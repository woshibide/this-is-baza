    Baza / UI examples (vanilla JS)

    UI examples

    Interactive controls for browser sketches, built with the vanilla JavaScript port. Each example shows a reusable way to edit a value, shape motion, or arrange a sequence. Changes save locally in this browser.

    Values

    A slider edits one number, such as copies, a delay, or a scale. Drag the number, step through values with the buttons, or enter a number within the chosen limits.

    Choices and toggles represent discrete settings. These examples show a mutually exclusive alignment, a shape selection, and an independent on/off option.

    Timing

    A Bézier ramp controls how a value changes over time. Move its handles to shape the acceleration and deceleration; the dot below the graph previews the resulting motion.

    A pulse envelope rises to a peak and returns to its starting value. Adjust the peak and curve handles to shape a swell, flash, or other temporary change.

    The timeline places motion in a sequence of steps, and the inspector beside it edits whatever is selected. Both curves above are the eases of its two tracks and play from the same clock. Click a step to inspect its duration; double-click it to drag its keyframes, which loops that step. See the workspace demo for the full layout.

    Timeline & inspector

    Steps, keyframed tracks, and the controls of the selection.

    Color

    A palette keeps a small set of colors together. Select a swatch to edit its color and opacity, or add and remove colors as the sketch needs.

    A gradient blends colors between stops. Move the stops to change where each color appears, and edit their colors and opacity independently.

    Range

    An interval defines a lower and upper value. Move either endpoint or shift the whole interval; here, the selected range also sets the pixel distances used by the two motion previews.

    An angle interval limits freedom of rotation to an allowed arc. Move either endpoint to resize it, or rotate the whole interval around the dial, including across 0°.

    Geometry

    An XY control places a point on a two-dimensional canvas. Drag the point for a visual adjustment, or enter exact coordinates and limits in the fields.

    An angle control sets direction or rotation. Use the dial for visual adjustments or enter degrees directly; complete turns are retained rather than discarded.

    A vector control sets direction and magnitude together. Rotate it like the angle dial, then slide the point along the line to set its length.

    Linked dimensions set width and height together. Lock the current aspect ratio to resize proportionally, or unlock it to change each dimension independently.
